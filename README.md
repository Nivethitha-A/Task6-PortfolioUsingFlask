# 🌐 Nivethitha’s Portfolio Website  

A modern **Flask-based portfolio website** built using **Python, Flask, HTML, CSS, and JavaScript**.  
This portfolio showcases my skills, projects, certifications, achievements, and includes a fully functional contact page.

---

## 🚀 Features

- 🏠 **Home Page** – Introduction + Hero section  
- 👩‍🎓 **About Page** – Education, certifications, internships  
- 🛠 **Projects Page/Section** – Showcases my real projects  
- 📩 **Contact Page** – Interactive form  
- 🎨 **Responsive UI** using custom CSS & JS  
- 🧩 **Reusable Templates** using Flask + Jinja2  
- 📦 **requirements.txt included** for easy setup

## 🛠 Tech Stack

- **Backend:** Python, Flask  
- **Frontend:** HTML, CSS, JavaScript  
- **Templating:** Jinja2  
- **Environment:** Virtualenv / Local Flask Server

## 📦 Installation & Setup

### 1️⃣ Install dependencies
```bash
pip install -r requirements.txt
```

### 2️⃣ Run the Flask application
```bash
python app.py
```

### 3️⃣ Open in your browser

http://127.0.0.1:5000/
